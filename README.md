## 📌 Sobre o Projeto

Este portfólio foi criado para servir como vitrine profissional, reunindo em um só lugar:

- Projetos desenvolvidos para clientes reais
- Cursos e certificações concluídos
- Formas de contato direto

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Uso |
|-----------|-----|
| HTML5 | Estrutura e semântica do site |
| CSS3 | Estilização e layout responsivo |
| Supabase | Backend as a Service (banco de dados/auth) |

---

## 📁 Estrutura do Projeto

```
portfolio-germano-dev/
├── index.html                  # Página principal
├── portfólio germano dev.html  # Versão alternativa
├── supabase-setup.sql          # Script de configuração do banco Supabase
└── README.md
```

> **`index.html`** → Ponto de entrada do site. Contém toda a estrutura HTML da página.
> **`supabase-setup.sql`** → Script SQL para criar as tabelas e configurações necessárias no Supabase.

---

## 🚀 Como Rodar Localmente

```bash
git clone https://github.com/vgermano1711/portfolio-germano-dev.git
cd portfolio-germano-dev
open index.html
```
